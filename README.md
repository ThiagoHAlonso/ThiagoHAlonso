# Thiago Alonso

Analista de QA em transição de carreira, vindo da área de suporte técnico. Atualmente curso Engenharia de Software na UNICSUL e estou construindo minha base em automação de testes, APIs e qualidade de software.

## Sobre mim

Trabalhei por cerca de dois anos e meio no suporte técnico do Atacadão São Miguel, lidando com chamados, sistemas internos e resolução de problemas no dia a dia de um CPD. Foi ali que percebi que queria trabalhar com qualidade de software de forma mais direta, e hoje estou migrando para QA enquanto termino a graduação.

Sou formado em Análise e Desenvolvimento de Sistemas pela Anhanguera e, em paralelo, estudo Java, automação com Cypress e testes de API com Postman. Também tenho interesse em aplicar IA a processos de QA, algo que venho testando em projetos pessoais.

## Projetos

**[qa-serverest-ai](https://github.com/ThiagoHAlonso/qa-serverest-ai)**
Automação de testes sobre a API ServeRest, combinando Postman/Newman e Cypress com uma camada de IA para geração de testes, revisão e análise de falhas, além de pipeline de CI/CD no GitHub Actions.

**[sql-exercicios](https://github.com/ThiagoHAlonso/sql-exercicios)**
Exercícios acadêmicos de SQL e MySQL, reunidos enquanto estudo banco de dados na faculdade.

**Automação E2E com Cypress**
Testes de ponta a ponta sobre o OrangeHRM, cobrindo login, atualização de dados cadastrais e validação de mensagens de erro, com fixtures para separar dados de teste do código.

**Testes de API com Postman**
Validação de endpoints usando a Star Wars API (SWAPI) para praticar testes de API fora do contexto de trabalho.
